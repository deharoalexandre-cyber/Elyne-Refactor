A local code-analysis and modernization product: it identifies defects and technical debt, proposes justified changes, and produces outputs for human review.

## Presented capabilities

- Deterministic scanning, contextual retrieval, and review assisted by several models.
- Before-and-after proposals, tests, and exportable reports depending on configuration.
- Designed to keep the analyzed code in the customer's environment.

## Scope

The website shows Production. The local document found describes version 1.4.1 from April 2026; this repository does not contain its code, test pipeline, or customer report. Proposed changes require review and validation in the target project.
