# Elyne Refactor

**Langues : Français · [English](README.en.md)**  
**Statut affiché au catalogue : Production (statut du catalogue)**

Un produit local d'analyse et de modernisation de code : il cherche les défauts et la dette technique, propose des corrections motivées, puis produit des sorties destinées à la revue humaine.

## Capacités présentées

- Analyse déterministe, recherche contextuelle et revue assistée par plusieurs modèles.
- Propositions avant/après, essais et rapports exportables selon la configuration.
- Conçu pour conserver le code analysé dans l'environnement du client.

## Périmètre

Le site affiche Production. La documentation locale retrouvée décrit la version 1.4.1 d'avril 2026 ; ce dépôt ne contient pas son code, sa chaîne de test ni de rapport client. Les corrections proposées nécessitent une revue et une validation dans le projet cible.
